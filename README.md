# skydog84.github.io

Root site for the skydog84 GitHub account.

It exists for one reason: AdMob crawls the developer website listed on the
SkyDog GPS App Store page — `skydog84.github.io` — looking for `app-ads.txt`.
Without this repo that URL 404s and every app on publisher
`pub-5768994898556694` is stuck on "Limited ad serving".

The app itself is served from the `skydog-gps` repo at skydoggps.com.
